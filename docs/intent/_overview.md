# intent/

Holds what cqrs-toolkit is *meant to do* at the level of the monorepo as a whole.
Slow-changing, deliberately edited.

## Contents

- [`vision.md`](vision.md) — what the project is and why.
- [`architecture.md`](architecture.md) — the structural shape: modules, layering, boundaries the toolkit assumes.
- [`non-goals.md`](non-goals.md) — what the project is deliberately *not* trying to be.
- [`glossary.md`](glossary.md) — vocabulary that spans packages (CQRS, ES, Result, EntityRef, etc.).

Project-specific intent (specs, requirements, non-goals scoped to one package or the demo system) lives in that project's own castle under `docs/projects/<name>/intent/`.
